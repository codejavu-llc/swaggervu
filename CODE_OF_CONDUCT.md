# Code of conduct

## Our commitment

We are committed to making SwaggerVu a welcoming, harassment-free project for
everyone, regardless of background, identity, experience level, or viewpoint.
Security research benefits from rigorous disagreement; it does not benefit from
personal attacks or intimidation.

## Expected behavior

- Be respectful, specific, and constructive.
- Critique evidence and technical claims, not people.
- Assume good intent while accepting corrections quickly.
- Protect private target data, vulnerability details, and credentials.
- Respect coordinated-disclosure requests and program scope.
- Help make the project accessible to new researchers and contributors.

Unacceptable behavior includes harassment, threats, discriminatory language,
doxxing, sexualized content, sustained disruption, publishing private security
information, or encouraging unauthorized use of the tool.

## Enforcement

Report conduct issues privately to the maintainers through the Codejavu organization
profile. Do not use a public issue when doing so would expose the reporter or sensitive
details. Maintainers may edit or remove content, close threads, reject contributions,
temporarily restrict participation, or permanently ban participants when necessary.

This policy applies in repository spaces and when someone officially represents the
project. Enforcement decisions will consider context, impact, recurrence, and safety.
