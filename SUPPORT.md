# Support

Use the channel that matches the problem:

- Questions, ideas, and workflow help: [GitHub Discussions](https://github.com/codejavu-llc/swaggervu/discussions).
- Reproducible bugs: [bug report](https://github.com/codejavu-llc/swaggervu/issues/new?template=bug_report.yml).
- False positives/negatives: use the evidence-quality issue form.
- Vulnerabilities in SwaggerVu: report privately as described in
  [SECURITY.md](SECURITY.md).

Before filing, run `swaggervu doctor`, check the latest release, and search existing
issues. Include `swaggervu --version`, OS/architecture, a minimal sanitized spec or
fixture, the command, and expected versus actual behavior. Never paste live tokens,
cookies, private API data, or embargoed vulnerability details.

Community support is best effort. Codejavu does not provide authorization to test a
third-party system and cannot adjudicate a bug-bounty program's scope.
